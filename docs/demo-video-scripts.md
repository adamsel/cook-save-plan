# Recipe Stash Demo Video Scripts

## Video Overview

| Video | Duration | Platform | Purpose |
|-------|----------|----------|---------|
| **Teaser** | 15-30s | TikTok, Reels, Twitter | Hook attention, drive to landing page |
| **Walkthrough** | 2-3 min | Landing page, YouTube | Full feature tour for interested users |
| **Story** | 60-90s | Instagram, YouTube Shorts | Relatable scenario showing the problem & solution |

---

## 1. Teaser Video (30 seconds)

### Script

```
[0:00-0:05] HOOK
Visual: Quick cuts - stressed person staring at fridge, calendar with question marks
Audio: "Sunday night. The fridge is empty. What are we eating this week?"

[0:05-0:12] AGITATE
Visual: Couple looking at phones separately, confusion
Audio: "You're texting recipes back and forth. Nobody knows what's planned."

[0:12-0:22] SOLUTION
Visual: Smooth screen recording of Recipe Stash
- Dragging "Overnight Oats" to Monday
- Setting 6 servings, leftovers auto-fill Tue-Wed
- Shopping list generating
Audio: "Recipe Stash. Plan meals together. One tap, your week is sorted."

[0:22-0:27] MAGIC MOMENT
Visual: Checking off items at the grocery store on phone
Audio: "Smart shopping lists. Ingredients merged. Organized by aisle."

[0:27-0:30] CTA
Visual: Recipe Stash logo + "recipestash.app"
Audio: "Plan meals together. Free to start."
```

### Shot List
1. Person opening empty fridge (stock or filmed)
2. Couple on phones looking frustrated
3. Screen recording: Adding meal to calendar
4. Screen recording: Leftovers auto-populating
5. Screen recording: Shopping list view
6. Hand checking off item on phone in store
7. Logo animation

### Production Notes
- **Music**: Upbeat, slightly anxious for problem → resolved and happy for solution
- **Text overlays**: Key phrases as captions (important for muted viewing)
- **Vertical format**: 9:16 for TikTok/Reels, can crop for stories

## 2. Walkthrough Video (2-3 minutes)

### Script

```
[0:00-0:15] INTRO
Visual: You at desk/kitchen with laptop
Audio: "Hey! Let me show you how my partner and I plan our meals for the week.
       It used to be chaos - now it takes 10 minutes on Sunday."

[0:15-0:40] ADDING RECIPES
Visual: Screen recording - Recipes page, clicking "Add Recipe"
Audio: "First, you add your recipes. You can import from any URL - just paste it
       and the app pulls in ingredients and instructions automatically.
       Or browse the Discover tab for inspiration."
Actions shown:
- Click "Add Recipe"
- Paste a URL
- Show it parsing

[0:40-1:10] MEAL PLANNING
Visual: Screen recording - Meal Plan page
Audio: "Here's the meal plan. Each day has breakfast, lunch, dinner.
       I'll drag Overnight Oats to Monday breakfast.
       Now here's the magic - I'm making 6 servings, so I'll set leftovers to 2.
       See how Tuesday and Wednesday automatically show 'leftover'?
       That's batch cooking built in."
Actions shown:
- Drag recipe to Monday
- Adjust servings to 6
- Set leftovers to 2
- Show Tue/Wed with leftover badges

[1:10-1:35] EVENT TRACKING
Visual: Screen recording - Edit meal sheet, event section
Audio: "Saturday we're having friends over for a BBQ.
       I'll add the recipe, then mark it as an event - 'Guests for 8'.
       Now the shopping list knows I need ingredients for 8 people,
       and the calories adjust per person too."
Actions shown:
- Add a recipe to Saturday
- Click to edit
- Select "Guests" event type
- Set guest count to 8
- Show the event badge on the card

[1:35-2:00] SMART SHOPPING LIST
Visual: Screen recording - Shopping List page
Audio: "The shopping list is where it all comes together.
       Every ingredient from the week, merged and organized.
       '2 onions' plus '1 onion' equals '3 onions'.
       It's sorted by grocery aisle, so I'm not running back and forth in the store.
       I can even see which recipes need each item."
Actions shown:
- Navigate to Shopping List
- Show merged ingredients
- Expand to show recipe sources
- Show aisle categories

[2:00-2:25] COLLABORATIVE PLANNING
Visual: Screen recording - Settings, Household section
Audio: "Best part? My partner and I plan together.
       In settings, you create a household and invite them.
       Now we see the same meal plan, same shopping list.
       No more 'I thought you were getting milk'."
Actions shown:
- Go to Settings
- Show Household section
- Show members list

[2:25-2:45] USING AT THE STORE
Visual: Phone in hand, checking items
Audio: "At the store, I just pull up the shopping list.
       Check items off as I go.
       Works offline too - perfect for stores with bad signal."
Actions shown:
- Open app on phone
- Check off a few items
- Show offline indicator (if demonstrating)

[2:45-3:00] CLOSING CTA
Visual: Back to you, then logo
Audio: "That's Recipe Stash. Meal planning for couples and families
       who batch cook and have lives.
       It's free to start - link in the description.
       Happy cooking!"
Actions shown:
- Wave/smile
- Cut to logo + URL
```

### Shot List
1. Talking head intro (you at desk or in kitchen)
2. Screen recording: Adding recipe from URL
3. Screen recording: Meal plan page, dragging recipe
4. Screen recording: Setting servings and leftovers
5. Screen recording: Adding event with guest count
6. Screen recording: Shopping list overview
7. Screen recording: Household settings
8. B-roll: Using phone in store (can be staged)
9. Talking head outro
10. Logo + CTA

### Production Notes
- **Screen recording**: Use clean demo data, nice recipe names
- **Zoom**: Use post-production zoom to highlight specific UI elements
- **Transitions**: Simple cuts or subtle zooms, nothing distracting
- **Background music**: Low, ambient, doesn't compete with voice
- **Captions**: Add for accessibility and muted viewing

## 3. Story Video (60-90 seconds)

### Script

```
[0:00-0:10] THE PROBLEM
Visual: Split screen - two people on phones texting
Text overlay: "When you both try to plan dinner..."
Audio: Message sounds
Chat bubbles appearing:
- "What do you want for dinner?"
- "idk what do you want"
- "Maybe tacos?"
- "We had tacos last week"
- "Fine you pick"

[0:10-0:20] THE STRUGGLE
Visual: Grocery store - one person looking confused at phone
Text overlay: "And then at the store..."
Audio: Ambient store sounds
Person looking at list, then at shelves, clearly lost

[0:20-0:30] THE DISCOVERY
Visual: Same person discovering Recipe Stash on phone
Text overlay: "Until we found Recipe Stash"
Audio: Upbeat music begins
App logo appears on screen

[0:30-0:50] THE SOLUTION
Visual: Couple sitting together, looking at laptop/tablet
Text overlay: "Now we plan together in 10 minutes"
Audio: Happy music
Quick cuts of:
- Dragging recipes to calendar
- Setting leftovers
- Shopping list generating

[0:50-1:05] THE PAYOFF
Visual: At store, easily checking items off
Text overlay: "Shopping is actually easy now"
Audio: Continued music
Quick cuts:
- Checking items off
- Ingredients going in cart
- Happy faces

[1:05-1:20] CLOSING
Visual: Couple cooking together, having fun
Text overlay: "Recipe Stash - Plan meals together"
Audio: Music resolves
Logo + "recipestash.app"
Text: "Free to start"
```

### Shot List
1. Split screen texting (can use screen recording of texts)
2. Person confused in grocery store (B-roll or staged)
3. Phone showing Recipe Stash logo
4. Couple at table/counter with laptop
5. Screen recording quick cuts (planning, list)
6. Person checking items at store
7. B-roll: Cooking together
8. Logo + CTA

### Production Notes
- **Tone**: Relatable, light, slightly humorous
- **Music**: Start slightly tense, transition to upbeat/resolved
- **Text overlays**: Essential for muted viewing
- **Format**: 9:16 vertical for Reels/TikTok/Stories

## Recording Checklist

### Before Recording

- [ ] Clean up Recipe Stash with demo data
  - Nice recipe names ("Creamy Garlic Pasta", "Overnight Oats")
  - Set household size to 2
  - Add a few meals to the week
- [ ] Hide any personal information
- [ ] Test screen recording tool
- [ ] Check microphone levels
- [ ] Prepare any physical props (phone, groceries)

### Demo Data Suggestions

**Recipes to feature:**
- Overnight Oats (great for batch cooking demo)
- Creamy Garlic Pasta (classic, recognizable)
- Chicken Stir Fry (good ingredient variety)
- BBQ Pulled Pork Sliders (good for event demo)
- Greek Salad (simple, healthy)

**Week layout:**
- Monday: Overnight Oats (breakfast, 6 servings → leftovers Tue/Wed)
- Monday: Quick Dinner
- Wednesday: Pasta (4 servings)
- Saturday: BBQ for event (8 guests)
